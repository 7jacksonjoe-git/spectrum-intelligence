# Spectrum Intelligence - Cognitive Radio AI
Built from scratch in Lagos, Oct 2026

## What it does
AI that automatically detects radio modulations: BPSK, QPSK, 8PSK, 16QAM
Real-time spectrum sensing for 5G / Military applications.

## Results
- Dataset: 1200 IQ signals (I/Q constellation)
- Model: MLP (128, 64)
- Accuracy: 100.0%
- Features: 2D histogram of IQ

## Files
- dataset.py - generates signals
- train.py - trains AI
- spectrum_ai.pkl - saved model
- detector.py - live detector
- final_report.png - results
